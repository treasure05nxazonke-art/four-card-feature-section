# 🧩 Four Card Feature Section

A responsive solution to the **Four Card Feature Section** challenge from Frontend Mentor. This project focuses on building a clean layout using CSS Grid and making it fully responsive across different screen sizes.

## 📚 What I Learned

This was one of the most challenging projects I have worked on so far. I initially tried using Flexbox for the layout, but it did not work well for positioning the cards.

Through this project, I learned how to:

- Use **CSS Grid** to create complex layouts
- Position elements using **grid rows and columns**
- Combine **Grid and Flexbox** effectively
- Build responsive layouts that adapt to different screen sizes
- Debug layout issues and improve structure

---

## ⚠️ Challenges

- Aligning the cards correctly was difficult  
- Moving the left and right cards upward while keeping balance was challenging  
- Understanding how CSS Grid works took time  
- Making the design responsive across multiple screen sizes  

I overcame these challenges by experimenting, adjusting my layout multiple times, and learning how Grid behaves.

---

## 🔄 What I Would Do Differently

- Start with a **mobile-first approach**
- Plan the layout structure before coding
- Avoid relying too much on `transform` for positioning
- Use cleaner Grid techniques for alignment

---

## ❓ Areas for Improvement

I would appreciate feedback on:

- Better ways to structure layouts using **CSS Grid**
- How to avoid using `transform` for layout positioning
- Improving responsiveness across all screen sizes
- Writing cleaner and more maintainable CSS
